# 雀の間 — 麻雀の役を覚えて、NPCと打つ

スマホのブラウザだけで遊べる麻雀の学習＆対局サイトです。インストール不要・時間制限なし。

## 中身

| ページ | 内容 |
| --- | --- |
| `index.html` | トップページ（両方へのリンク） |
| `yaku-dojo.html` | **役マスター道場** — 牌と用語の図解、役図鑑、鳴きクイズ、役当てクイズ |
| `mahjong/index.html` | **四人打ち麻雀** — NPC3人と対局。時間制限なし |

## 対局のルール（雀魂準拠）

- 25000点持ち **30000点返し**、ウマ **+15 / +5 / -5 / -15**（オカは1位が総取り）
- 赤ドラ3枚（赤5萬・赤5筒・赤5索 各1枚）／裏ドラ・一発あり
- **頭ハネ** — ダブロンなし。捨てた人に最も近い1人だけが和了
- **フリテン** — 自分の捨て牌・見逃し（同巡内）・リーチ後の継続フリテンに対応
- **槓ドラ** — 暗槓は即めくり、明槓・加槓は打牌後にめくる
- **食い替え禁止**（チーの筋食い替えを含む）
- **途中流局** — 九種九牌／四風連打／四家立直／四槓散了
- **流し満貫**あり
- ノーテン罰符3000点、親はテンパイで連荘、トビ終了あり
- 規定局数で誰も30000点に届かなければ**南入／西入**（サドンデス）
- 数え役満・複合役満・ダブル役満（大四喜／四暗刻単騎／国士十三面／純正九蓮）

## アシスト機能（初心者向け）

対局中いつでもON/OFFできます。

- **おすすめの打牌** — 向聴数 → 受け入れ枚数 → 危険度の順で最善手を提示（手牌に緑枠）
- **待ちの表示** — テンパイ時の待ち牌と残り枚数、フリテン警告
- **狙える役** — 今の手から現実的に狙える役と、その達成度
- **危険牌の色分け** — リーチ者に対する現物／スジ／無スジを判定して手牌に着色

## 開発

依存パッケージなしの素の HTML/CSS/JavaScript です。ローカルで動かす場合:

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

ロジックは DOM に依存していないため、Node からそのままテストできます。

```
mahjong/engine.js  牌・面子分解・向聴数・役判定・点数計算
mahjong/game.js    対局進行の状態機械 + NPC AI
mahjong/assist.js  受け入れ計算・打牌推奨・危険度・狙える役
mahjong/tiles.js   牌のSVG描画
mahjong/ui.js      画面描画と操作
```
